Privacy Policy

Last updated: November 2026

This application ("Job Search Pipeline") is a personal, non-commercial tool that runs locally on the developer's own device (a Raspberry Pi).

1. What data is accessed?

The application uses the Gmail API to read job-related newsletter emails from the developer's own Gmail inbox. It does not access, read, or store any other emails.

2. How is data used?

The email content is parsed only to extract job posting information (e.g., title, company, description). This information is stored locally in a private database on the developer's device. It is never shared with third parties, sold, or used for advertising.

3. Data storage and security

All data is stored locally on the developer's own hardware. No data is transmitted to or stored on external servers controlled by the developer.
